💼 政府標案全自動化發報系統

發報系統運作架構與流程報告書（管理決策版） | 報告時間：2026-05-20

本報告書旨在向管理階層說明「政府電子採購網標案全自動化系統」的整體架構與運作邏輯。本系統成功打通地端與雲端，實現每日自動進行標案搜尋、智慧篩選、色彩排版著色、截圖，並將視覺化報表第一時間推送至 LINE 工作群組，大幅提升標案評估與決策效率。

🔗 點此開啟今日 Google 雲端試算表
一、 系統運作六大核心流程
1 自動定時啟動（讀取配置）
每日早晨由 Windows 工作排程器定時觸發程式，自動讀取 Obsidian 配置檔的搜尋關鍵字。
⬇
2 模擬請求政府電子採購網
Python 自動發送 HTTP 請求，模擬進階搜尋（精準鎖定「勞務類」標案，免去手動登入查詢）。
⬇
3 地端智慧多維度篩選
排除非核心地區（如東部、高屏與離島），限制預算上限，並安全保留未公開金額（空白）的案件。
⬇
4 雲端 Sheets 寫入與金額排序
自動於 Google 試算表建立當日日期分頁，將符合條件的標案以「金額由大到小」降序排列寫入。
⬇
5 智慧視覺著色標記
系統寫入時自動分析案名，針對學校、設計規劃、景觀運動、室內修繕、防水拉皮套用專屬底色與字體。
⬇
6 自動 Chrome 截圖與 LINE 發送
啟動背景 Chrome 瀏覽器對試算表進行網頁截圖，透過 Discord 緩存中轉，以 LINE 機器人推送至群組。

三、 系統模塊詳細架構
1. 地端 Python 抓取與篩選模組

自動化查詢：繞過繁瑣網頁點選，秒級獲取 PCC 採購網數據。

地區過濾：排除雙北、宜花東、高屏、離島等，聚焦核心業務地區。

容錯處理：對於金額未公開案件，程式自動補 0 放行，保證關鍵設計案不漏失。

2. Google Sheets API 雲端排版模組

自動排序：打破網頁亂序狀態，高預算案置頂呈現。

局部字體美化：C欄內所有「核心關鍵字（如：設計/監造）」會執行局部文字標紅、加粗，其餘內容維持原樣。

自適應排版：動態調整欄位寬度、開啟自動換行，確保行動端文字不重疊。
